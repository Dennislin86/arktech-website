# Arktech SEO Structure

## SEO Positioning

Arktech should be positioned as an English B2B manufacturing website for European and North American buyers.

Primary positioning:

Tooling & Manufacturing Partner for OEMs and Injection Molders

Core business themes:

- Export injection molds
- Plastic injection molding
- Die casting mold manufacturing
- CNC metal parts
- Plastic and metal assembly
- DFM engineering support

Primary conversion goal:

Request a Quote / Upload RFQ Files

## Case Study Template

Each case study should be written as a technical B2B proof page, not a marketing story.

### Recommended URL Pattern

- `/case-studies/[industry-or-part-name]`

Examples:

- `/case-studies/automotive-sensor-housing-tooling`
- `/case-studies/medical-device-cartridge-molding`
- `/case-studies/smart-home-plastic-housing`
- `/case-studies/die-cast-control-housing`

### Case Study Page Structure

#### 1. Project Overview

Fields:

- Project name
- Customer type
- Region
- Product category
- Service scope

Example:

- Project name: Smart Home Plastic Housing
- Customer type: OEM Product Company
- Region: North America
- Product category: Smart home device
- Service scope: DFM, mold manufacturing, plastic injection molding, assembly review

#### 2. Customer Challenge

Explain:

- What the buyer needed
- What manufacturing risks existed
- Why the project required engineering review

Questions to answer:

- Was the part cosmetic?
- Were tolerances difficult?
- Were there assembly risks?
- Were there material or lead-time constraints?

#### 3. Arktech Solution

Explain:

- DFM changes
- Tooling strategy
- Material or process recommendations
- Sampling and correction process
- Inspection plan

#### 4. Manufacturing Scope

Include:

- Mold type
- Material
- Surface finish
- Cavitation
- Secondary operations
- Inspection method
- Packaging method

#### 5. Result

Use factual outcomes:

- Improved manufacturability
- Reduced tooling risk
- Stable sampling
- Clear inspection standard
- Better assembly fit
- Export-ready shipment

Avoid unsupported claims such as exact cost savings unless documented.

#### 6. Related Services

Link to:

- Relevant service page
- Relevant tooling example page
- Relevant industry page
- Request a Quote

### Case Study Metadata Template

Title:

`[Product / Part Type] Case Study | Arktech`

Description:

`See how Arktech supported [customer type] with [service scope] for a [product category] project requiring [key engineering challenge].`
